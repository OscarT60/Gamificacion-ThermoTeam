# ThermoTeam

Proyecto de gamificación desarrollado para Thermo Fisher.

## Tecnologías

- Node.js
- Express.js
- PostgreSQL
- Docker
- Docker Compose

## Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/OscarT60/Gamificacion-ThermoTeam.git
```

2. Entrar al proyecto

```bash
cd Gamificacion-ThermoTeam
```

3. Levantar Docker

```bash
docker compose up -d
```

4. Instalar dependencias del backend

```bash
cd backend-gamificacion
npm install
```

5. Iniciar el servidor

```bash
npm start
```

El backend estará disponible en:

```
http://localhost:3000
```
